# Mission

**Product:** ODA operational property-management workspace  
**Not:** a GCSS-Army / APSR replacement or Army-wide property book

## Who it’s for

First user: Ryan Appelhof — 18E on ODA 1223, 1st SFG (A), JBLM.

An ODA (~12-person SF team) needs one place to understand, inventory, organize, move, and manage team property.

## Core sources to connect

1. Hand receipt / Sub-hand receipt (SHR) — accountability & responsibility  
2. Property picture book — visual ID (Official + Actual + photo)  
3. Local trackers — custody / location / status  
4. DD Form 1750s — packing / containers (awareness; packing layer)

## Structure (how this ODA runs)

- UIC → ODA hand receipt → section SHRs: **Bravo / Charlie / Delta / Echo / Fox**
- Picture book attaches to the **HR line item**
- App is a **companion** to GCSS/APSR

## Priorities

- **P0** Reliable property foundation (done in Sprint 1)  
- **P1** Daily property mgmt + movement management  
- **P2** Doc automation (2062/1750) + workflow improvements  
- **P3** Multi-ODA / higher echelons later
