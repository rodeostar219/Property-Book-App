# Layered model

Do **not** flatten into one `property_item`.

1. **Formal accountability** — what the hand receipt / APSR says  
2. **Responsibility** — who signed (HR / SHR)  
3. **Components** — end item vs COEI / BII / AAL / CHR  
4. **Physical organization** — DD 1750 boxes/kits (page ≠ container)  
5. **Custody / location** — who has it / where it is (tracker ≠ DB of record)  
6. **Visual ID** — Official + Actual/common name + photo

**Conflict rule:** if sources disagree → open a discrepancy; never silent-merge.

**Doc types:** DA Form 2062 (responsibility) ≠ DD Form 1750 (packing).
